## Conceptos basicos del software
**Software**
programas de computadora, procedimientos y posiblemente documentación y datos asociados, referentes a la operación de un sistema de computación

**Ciclo de vida de desarrollo de software:** 
periodo de tiempo que comienza con la decisión de desarrollar un producto software y termina cuando el software es entregado. Típicamente incluye las fases de requerimientos, diseño, implementación y pruebas, y en ocasiones también las fases de instalación y puesta en marcha.

**Ciclo de vida del software:** 
periodo de tiempo que empieza cuando se concibe un producto software y termina cuando el software no está más disponible para su uso. 
*Típicamente incluye las siguientes fases:* 
1. Conceptualización 
2. Requerimientos 
3. Diseño 
4. Implementación 
5. Pruebas 
6. Instalación y puesta en marcha 
7. Operación y mantenimiento 
8. Retiro
**Proceso de software:** 
es una secuencia de actividades que conducen a la elaboración de un producto de software.  Cada actividad posee unas entradas y unas salidas. 
Las salidas son productos parciales que forman parte del producto final: el sistema software funcionando y entregado al cliente. 
**Producto de software:**
Conjunto completo de programas de computadora, procedimientos, y posiblemente documentación y datos asociados, diseñados para ser entregados al usuario.   

**Sistema:** 
conjunto de componentes o elementos con características y funcionalidad propias, que están relacionados y que trabajan en conjunto con el fin de alcanzar un objetivo, resultado o resolver un problema. 

**Sistema software:** 
1. Componentes funcionales o funciones 
2. Estructuras de datos o configuración de datos
3. Documentación 
4. Interfaces 
5. Componentes no funcionales 
6. Componentes dinámicos

el software no tiene características físicas como el hardware: 
1. El software se desarrolla o modifica con intelecto, no se manufactura en el sentido clásico.
2. El software no se “desgasta”.

 La industria se mueve hacia la construcción basada en componentes, la mayor parte del software se construye para un uso individualizado.
## Ingenieria de Software 
Es una disciplina o área de la Informática o Ciencias de la Computación, que ofrece métodos y técnicas para desarrollar y mantener software de calidad que resuelven problemas de todo tipo.

## Dominios de aplicación del software
existen 7 grandes categorías

### **Software de sistemas:** 
conjunto de programas escritos para dar servicio a otros programas.
Unos procesan estructuras de información complejas pero deterministas (si es posible predecir el orden y momento de las entradas, el procesamiento y las salidas)
*Ejemplos:* compiladores, editores y herramientas para administrar archivos.

Otras aplicaciones procesan sobre todo datos indeterminados (denominado software no determinista, que sucede si no pueden predecirse el orden y momento de las entradas, el procesamiento y las salidas).
*Ejemplos*: componentes de sistemas operativos, manejadores, software de redes, procesadores de telecomunicaciones.

**Características del software de sistemas:** 
- Gran interacción con el hardware de la computadora. 
- Uso intensivo por parte de usuarios múltiples. 
- Operación concurrente que requiere secuenciación. 
- Recursos compartidos y administración de un proceso sofisticado.
- Estructuras complejas de datos e interfaces externas múltiples.
###  Software de aplicación:
programas aislados que resuelven una necesidad específica de negocios.
procesan datos comerciales o técnicos que facilitan las operaciones de negocios o la toma de decisiones administrativas o técnicas
se usan para controlar funciones de negocios en tiempo real, como: 
Procesamiento en puntos de venta 
Control de manufactura en tiempo real
### Software de ingeniería y ciencias:
resuelve problemas en las áreas de ingeniería y científicos, usando algoritmos numéricos sofisticados
estas aplicaciones están abandonando los algoritmos numéricos convencionales, gracias a que se pueden usar tecnologías como el diseño asistido por computadora (CAD), la simulación de sistemas y otras aplicaciones interactivas
*ejemplos*: astronomía, vulcanología, análisis de tensiones en automóviles, dinámica orbital del transbordador espacial

### Software incrustado o embebido (embedded system):
Reside dentro de un producto o sistema y se usa para implementar y controlar características y funciones para el usuario final y para el sistema en sí. Es un software solo de lectura.
Ejecuta funciones limitadas y particulares, como el control de un horno microondas o provee una capacidad significativa de funcionamiento y control,
### Software de línea de productos (Software Products Line-SPL):
Diseñado para proporcionar una capacidad específica para uso de muchos consumidores diferentes. Se basa en la reutilización de software.
También se dirige a mercados masivos de consumidores, tales como: procesamiento de textos, hojas de cálculo, gráficas por computadora, multimedios, entretenimiento, administración de base de datos y aplicaciones para finanzas personales o de negocios
### Aplicaciones web:
son poco más que un conjunto de archivos de hipertexto vinculados que presentan información con uso de texto y gráficas limitadas
Pero desde la Web 2.0, las webapps han evolucionado están integradas con bases de datos corporativas y aplicaciones de negocios.
### Software de inteligencia artificial:
hace uso de algoritmos no numéricos para resolver problemas complejos que no son fáciles de tratar computacionalmente o con el análisis directo.
**Las aplicaciones incluyen:** 
- Robótica 
- Sistemas expertos 
- Reconocimiento de patrones (imagen y voz) 
- Redes neuronales articiales 
- Demostración de teoremas y juegos
#### Nuevos desafios 
1. **Computación en un mundo abierto:** 
que ha sido posible gracias al rápido crecimiento de las redes inalámbricas, lo que ha llevado a la aparición de la computación ubicua y distribuida
El desafío es desarrollar software de sistemas y aplicación que permita a los dispositivos móviles, computadores personales y sistemas empresariales comunicarse a través de redes enormes.
2. **Construcción de redes:** 
la red mundial WWW (World Wide Web) se ha convertido tanto en un motor de computación como en un proveedor de contenido
El desafío es hacer arquitecturas sencillas, como planeación financiera personal y aplicaciones sofisticadas que proporcionen un beneficio a mercados objetivo de usuarios finales en todo el mundo.
3. **Fuente abierta:**
distribución de código fuente gratuito para aplicaciones de sistemas, como sistemas operativos, bases de datos y ambientes de desarrollo, de modo que mucha más gente pueda contribuir a su desarrollo
El desafío es elaborar código fuente autodescriptivo y desarrollar técnicas que permitan a consumidores y desarrolladores saber cuáles son los cambios hechos y cómo se manifiestan dentro del software.
### Software heredado (legacy systems):
software desarrollado hace muchas décadas y que continúa siendo utilizado porque continúan siendo un apoyo para las funciones básicas del negocio y son “indispensables” para éste.
se caracteriza por su longevidad e importancia crítica para el negocio, pero en muchas ocasiones son de mala calidad.
**En ocasiones los sistemas heredados:** 
- Tienen diseños que no son susceptibles de extenderse 
- Código confuso 
- Documentación mala o inexistente
- Casos y resultados de pruebas que nunca se archivaron 
- Una historia de los cambios mal admnistrada

si el software heredado satisface las necesidades de sus usuarios y corre de manera confiable, entonces no falla ni necesita repararse.

**los sistemas de software evolucionen por una o varias de las siguientes razones:** 
- El software debe adaptarse para que cumpla las necesidades de los nuevos ambientes de cómputo y tecnología. 
- El software debe ser mejorado para implementar nuevos requerimientos del negocio. 
- El software debe ampliarse para que sea operable con otros sistemas o bases de datos modernos.  La arquitectura del software debe rediseñarse para hacerla viable dentro de un ambiente de redes.
se debe hacer la reingeniería del sistema heredado para que sea viable en el futuro
