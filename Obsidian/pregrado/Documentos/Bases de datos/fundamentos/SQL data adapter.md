> [!info] Explicación
> Un `DataAdapter` en entornos como .NET sirve como puente entre un `DataSet` (o `DataTable`) y una base de datos para recuperar y guardar información. Cuando trabajamos con interfaces gráficas, componentes como el `DataGridView` utilizan estos datos tabulares para presentarlos al usuario.

El componente `DataGridView` sirve para mostrar la información de forma estructurada y elegante en aplicaciones gráficas. 

Con este método se usa el `DataTable` (poblado frecuentemente por un DataAdapter) para que la relación (tabla) de la base de datos se presente al usuario final de una manera mucho más legible y amigable.
