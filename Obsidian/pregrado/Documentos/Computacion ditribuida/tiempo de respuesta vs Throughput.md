## Tiempo de respuesta
se refiere al tiempo total que tarda un sistema en responder a una solicitud desde el momento en que se hace la solicitud hasta el momento en que se recibe la respuesta
- **Medida en:** Generalmente en milisegundos (ms) o segundos (s).
- **Importancia:** Es crucial para la experiencia del usuario. Un tiempo de respuesta bajo es fundamental para aplicaciones en tiempo real y sistemas interactivos, como videojuegos, aplicaciones web y servicios financieros.
## Throughput
se refiere a la cantidad de trabajo que un sistema puede manejar en un período de tiempo determinado.
- **Medida en:** Generalmente en unidades por segundo (transacciones por segundo, solicitudes por segundo, etc.).
- **Importancia:** Es una medida de la capacidad del sistema. Un throughput alto significa que el sistema puede manejar una gran cantidad de trabajo o solicitudes simultáneamente, lo cual es esencial para sistemas de alta carga, como servidores web, bases de datos y redes de comunicación.
## Diferencia
- **Enfoque:**
    
    - **Tiempo de respuesta:** Se centra en la velocidad con la que se completa una sola solicitud.
    - **Throughput:** Se enfoca en la cantidad de trabajo que el sistema puede manejar en un período de tiempo.
- **Relación:**
    
    - **Tiempo de respuesta bajo:** No siempre implica un throughput alto. Un sistema puede ser muy rápido para responder a una solicitud individual pero no poder manejar muchas solicitudes simultáneamente.
    - **Throughput alto:** No siempre implica un tiempo de respuesta bajo. Un sistema puede manejar muchas solicitudes simultáneamente, pero si cada solicitud toma mucho tiempo en completarse, el tiempo de respuesta será alto.
- **Aplicaciones:**
    
    - **Tiempo de respuesta:** Importante para la experiencia del usuario y aplicaciones en tiempo real.
    - **Throughput:** Importante para la capacidad y eficiencia del sistema en entornos de alta carga.
