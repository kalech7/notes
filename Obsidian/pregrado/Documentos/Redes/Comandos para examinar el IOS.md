Estos comandos sirven tanto para el **Switch/Router.**

- Con este comando podremos obtener mucha información:
    - Versión del sistema operativo.
    - Tiempo de actividad.
    - Densidad de puertos.
    - La imagen del IOS (Siempre se pregunta en el examen)

```cisco
Switch# show version
```
Si tengo una arquitectura fullduplex a 1000 mbps el rendimiento es de 200 Mbps
