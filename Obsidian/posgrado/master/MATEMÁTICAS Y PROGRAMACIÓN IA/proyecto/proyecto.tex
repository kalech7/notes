\section{Tema}
% =========================================================================
\textbf{Detección de suplantación de identidad frente a variaciones naturales del comportamiento mediante biometría conductual, Feature Engineering y Machine Learning.}

% =========================================================================
\section{Descripción de la Propuesta}
% =========================================================================

\subsection{Descripción Funcional}
Los mecanismos tradicionales de autenticación permiten verificar la identidad del usuario
principalmente al inicio de una sesión, pero no garantizan que la misma persona continúe
utilizando el sistema posteriormente.
Esta limitación cobra mayor relevancia ante posibles suplantaciones realizadas tanto por
terceros como por herramientas automatizadas o agentes basados en Inteligencia Artificial.
Frente a este problema, el proyecto propone desarrollar un sistema de
\textbf{autenticación continua} basado en \textbf{biometría conductual}, analizando en segundo
plano los patrones de interacción del usuario mediante teclado y mouse a lo largo de la sesión.

\begin{enumerate}
    \item \textbf{Comportamiento habitual del usuario legítimo.}
    \item \textbf{Variaciones naturales del comportamiento} del mismo usuario entre diferentes sesiones temporales.
    \item \textbf{Comportamiento de suplantación} ejecutado por un tercero o mediante herramientas automatizadas (bots).
\end{enumerate}

\textbf{Pregunta de investigación:} \textit{¿Qué características obtenidas mediante Feature Engineering permiten distinguir variaciones naturales del usuario legítimo frente a una suplantación de identidad?}

\textbf{Datasets públicos y gratuitos a utilizar:}
\begin{itemize}
    \item \textbf{Balabit Mouse Dynamics Challenge Dataset:} Benchmark público con sesiones de interacción de múltiples usuarios en entornos reales, capturando coordenadas $(x, y, t)$, acciones de clic y vectores de trayectoria.\\
    Enlace de descarga: \url{https://github.com/balabit/Mouse-Dynamics-Challenge}
    \item \textbf{Keystroke and Mouse Dynamics for UEBA Dataset (Mendeley Data):} Dataset público de biometría conductual que contiene más de 142\,000 registros de interacción de 11 usuarios, incluyendo eventos de teclado y dinámicas de mouse recopilados mediante una aplicación web.\\
    Enlace de descarga: \url{https://data.mendeley.com/datasets/f78jsh6zp9/2}
\end{itemize}

\textbf{Definición de clases y escenario de evaluación:}
\begin{itemize}
    \item \textbf{Clasificación Binaria Supervisada:} Clase 0 (Usuario Legítimo, integrando sesiones base y de variación natural) vs. Clase 1 (Impostor, conformado por sesiones de usuarios ajenos y patrones anómalos).
    \item \textbf{Detección de Anomalías (One-Class):} Perfilado entrenado exclusivamente con el comportamiento del usuario legítimo para evaluar umbrales dinámicos frente a variaciones legítimas vs. ataques.
\end{itemize}

\textbf{Pipeline y Arquitectura de Implementación:}
\begin{enumerate}
    \item \textbf{Ingesta y Preprocesamiento:} Limpieza de datos y filtrado de ruido.
    \item \textbf{Feature Engineering:} Extracción de descriptores cinemáticos y temporales (tiempos de vuelo, pulsación, velocidad de tipeo, aceleración de cursor, curvatura de trayectorias, cambio angular y pausas cognitivas).
    \item \textbf{Análisis Estadístico y Selección:} Analizar qué características se mantienen relativamente estables para un mismo usuario y cuáles permiten diferenciarlo de otros usuarios.
    \item \textbf{Entrenamiento y Comparación de Modelos:} Entrenar modelos utilizando variables base y características obtenidas mediante \textit{Feature Engineering}, comparando su rendimiento con \textbf{Random Forest} para clasificación y \textbf{Isolation Forest} para detección de anomalías.
    \item \textbf{Validación por Sesión:} Entrenar y evaluar el modelo usando sesiones diferentes del usuario para comprobar su capacidad de generalización.
    \item \textbf{Métricas de Evaluación:} \textit{Accuracy}, \textit{Precision}, \textit{Recall} y \textit{F1-Score}.
\end{enumerate}

\textbf{Tema de investigación complementario (fuera del alcance del curso):}\\
Se investigarán los fundamentos teóricos de la Biometría Conductual Continua,
el fenómeno de Behavioral Drift, las limitaciones de confiabilidad de los mecanismos
CAPTCHA y el uso de técnicas de interpretabilidad como SHAP,
con el objetivo de comprender cómo estas herramientas pueden ayudar a explicar qué
características conductuales influyen en la detección de suplantaciones.

\section{Objetivos}
% =========================================================================

\subsection{Objetivo General}
Desarrollar y evaluar un sistema de Machine Learning fundamentado en Feature Engineering para la autenticación continua mediante biometría conductual de teclado y mouse, capaz de superar las limitaciones de confiabilidad de los métodos tradicionales y discriminar de forma robusta entre variaciones naturales del usuario legítimo y suplantaciones de identidad.

\subsection{Objetivos Específicos}
\begin{enumerate}
    \item \textbf{Obtener y preparar} datasets públicos de biometría conductual de teclado y mouse.

    \item \textbf{Extraer características} temporales y de movimiento mediante técnicas de \textit{Feature Engineering}.

    \item \textbf{Analizar} qué características permiten diferenciar el comportamiento de un usuario legítimo frente al de un impostor.

    \item \textbf{Entrenar y comparar} modelos de clasificación y detección de anomalías utilizando datos base y características obtenidas mediante \textit{Feature Engineering}.

    \item \textbf{Evaluar} el rendimiento de los modelos mediante métricas de evaluación (\textit{Accuracy}, \textit{Precision}, \textit{Recall} y \textit{F1-Score}).
\end{enumerate}
